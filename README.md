# Park Hyokyung 홈페이지

글은 `src/writing` 폴더에 파일 하나로 씁니다. 저장하면 1~2분 뒤 사이트에 저절로 반영됩니다.

---

## 처음 한 번: 사이트 열기

1. **GitHub 가입**: github.com에서 가입합니다. 사용자 이름이 사이트 주소가 됩니다. 이름을 `parkhyokyung`으로 정하면 주소는 `parkhyokyung.github.io`입니다.
2. **저장소 만들기**: 오른쪽 위 `+` → `New repository`. 이름 칸에 `사용자이름.github.io`를 그대로 적고(예: `parkhyokyung.github.io`), `Public`을 고른 뒤 `Create repository`를 누릅니다.
3. **파일 올리기**: 새 저장소 화면의 `uploading an existing file`을 누르고, 압축을 푼 폴더 **안의** 파일과 폴더를 모두 끌어다 놓습니다. 아래 `Commit changes`를 누릅니다.
   - `.github` 폴더는 숨김 폴더입니다. 맥 Finder에서는 `Cmd + Shift + .`을 누르면 보입니다. 이 폴더가 빠지면 사이트가 만들어지지 않습니다.
4. **Pages 켜기**: 저장소의 `Settings` → 왼쪽 `Pages` → `Source`를 `GitHub Actions`로 바꿉니다.
5. **확인**: 저장소의 `Actions` 탭에 초록 체크가 뜨면 주소로 접속합니다. 빨간 X가 떠 있으면 그 줄을 눌러 `Re-run all jobs`를 누릅니다. 4번보다 3번이 먼저 실행돼서 생기는 일이라 한 번 다시 돌리면 됩니다.

## 글쓰기 화면: Pages CMS

1. app.pagescms.org에 접속해 `Sign in with GitHub`으로 로그인합니다.
2. 처음 한 번 GitHub이 접근 허락을 묻습니다. 사이트 저장소를 허락합니다.
3. 저장소를 고르면 왼쪽에 **글** 메뉴가 보입니다. 기존 글 목록이 작성일 순으로 나옵니다.
4. `Add an entry`로 새 글을 만들고 칸을 채웁니다. 본문은 일반 글쓰기 창입니다. 대표 사진은 `대표 사진` 칸에서 바로 올립니다.
5. `Save`를 누르면 1~2분 뒤 사이트에 반영됩니다.

**주소용 영문 이름**은 글을 처음 만들 때 파일 이름과 글 주소가 됩니다. 나중에 고쳐도 주소는 바뀌지 않습니다.

## 새 글 쓰기: GitHub에서 직접

Pages CMS가 안 될 때 쓰는 방법입니다.

1. 저장소에서 `src` → `writing` 폴더로 들어가 `Add file` → `Create new file`을 누릅니다.
2. 파일 이름을 `작성일-영문이름.md`로 짓습니다. 예: `2026-10-20-gullivers.md`
   - 날짜는 목록 순서와 "작성" 날짜가 됩니다.
   - 영문이름은 글 주소가 됩니다. `사이트주소/writing/gullivers/`
3. 아래 틀을 붙여 넣고 채웁니다.
4. `Commit changes`를 누르면 끝입니다.

```
---
title: "글 제목"
slug: gullivers
category: criticism
date: 2026-10-20
work: "극단 이름 〈작품명〉"
source: "실린 매체"
seen: 2026-10-12
image: /assets/images/사진파일.jpg
image_alt: "사진 설명. 화면을 못 보는 독자가 듣는 문장"
caption: "사진 제공 극단 이름"
info: |
  연극 〈작품명〉
  2026.10.01.-10.12. 극장 이름
  극단 이름 / 작·연출 누구
---

첫 문단.

둘째 문단. 문단 사이는 빈 줄 하나로 띄웁니다.
```

### 칸 설명

| 칸 | 쓰는 것 | 없으면 |
|---|---|---|
| `title` | 글 제목. 목록에서 ｢ ｣가 자동으로 붙습니다 | 꼭 필요 |
| `category` | `criticism` 비평, `programme` 프로그램 글, `academic` 논문 | 꼭 필요 |
| `work` | 작품, 단체 | 생략 가능 |
| `source` | 실린 매체 (사이:비평, 『한국연극』 등) | 생략 가능 |
| `seen` | 관람일 | "관람" 날짜를 안 보여 줌 |
| `link` | 원문 주소 | 원문 링크를 안 보여 줌 |
| `image` | 사진 경로 | 사진 없이 시작 |
| `info` | 글 끝 공연 정보. 줄바꿈 그대로 나옵니다 | 생략 가능 |

### 링크만 거는 글

다른 매체에 실린 글을 전문 없이 목록에만 올리려면 `---` 아래 본문을 비워 두고 `link`만 적습니다. 목록에서 제목을 누르면 원문으로 바로 갑니다. 본문을 쓰면 사이트 안에 글 페이지가 생기고, 목록에 첫 문장이 함께 보입니다.

### 사진 올리기

`src` → `assets` → `images` 폴더에서 `Add file` → `Upload files`로 올립니다. 파일 이름은 영문으로 짓고, 글의 `image` 칸에 `/assets/images/파일이름.jpg`로 적습니다. 가로 1800px 안팎이면 충분합니다.

### 본문에서 쓸 수 있는 표시

- 인용 단락: 줄 앞에 `> `
- 소제목: 줄 앞에 `## `
- 기울임: `*글자*`

### 고치기와 지우기

글 파일을 열어 연필 아이콘으로 고치고 `Commit changes`를 누릅니다. 지우려면 파일 화면의 `···` → `Delete file`입니다.

## 내 도메인 연결 (예: parkhyokyung.com)

1. 도메인 등록 업체에서 도메인을 삽니다.
2. 저장소 `Settings` → `Pages` → `Custom domain`에 도메인을 적고 `Save`. **DNS 설정보다 이 단계를 먼저** 합니다.
3. 등록 업체의 DNS 관리 화면에 아래 레코드를 넣습니다. 업체가 미리 넣어 둔 A 레코드나 주차 페이지 레코드는 지웁니다.

| 종류 | 호스트 | 값 |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | 사용자이름.github.io |

4. 반영을 기다립니다. 몇 분에서 하루까지 걸립니다. `Custom domain` 칸 아래 확인 표시가 초록으로 바뀌면 됩니다.
5. `src/_data/site.json`의 주소를 새 도메인(예: `https://parkhyokyung.com`)으로 고칩니다. 링크 미리보기 사진이 이 주소를 씁니다.
6. 같은 화면의 `Enforce HTTPS`를 켭니다. 켤 수 있게 되기까지 최대 24시간이 걸립니다.
7. 권장: GitHub 오른쪽 위 프로필 → `Settings` → `Pages`에서 도메인 소유 확인(verify)을 해 두면, 남이 같은 도메인을 자기 GitHub에 거는 일을 막습니다.
